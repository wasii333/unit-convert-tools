Frequently Asked Questions

Answers to the questions people ask most about UnitConvert.

Are the UnitConvert converters really free?＋
Yes. All 1000 converters on UnitConvert are free, with no sign-up and no usage limits.
Do my values or files leave my device?＋
No. Every conversion runs locally in your browser. Numeric and text tools never send anything anywhere; file tools process your file on your own device and the converted file is downloaded straight to you.
How accurate are the conversions?＋
Numeric converters use exact international factors where they exist (for example 1 inch = 2.54 cm exactly). Special tools such as calendars and coordinates use standard published algorithms.
Can I use these converters on my phone?＋
Yes. The site is fully responsive — the tool grid, search and converter all work on mobile.
What is UnitConvert?＋
UnitConvert is a free collection of 1000 converters in 50 categories of 20 tools each — units, physics, science, text, data formats, media, colour and files.
Why do some tools ask for an extra value?＋
Some conversions need a reference value — for example a molar mass, a density, or a temperature. The converter asks for it so the result is correct for your exact case.
Can I copy a result?＋
Yes. Every converter has a Copy button (numeric and text tools), and file tools give you a direct download.
Do the tools work offline?＋
Once the page is loaded, the converters themselves need no internet connection — everything runs in your browser.
